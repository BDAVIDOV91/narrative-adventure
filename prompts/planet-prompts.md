# Planet & Celestial Body Prompts

**Important:** planets and moons use **real NASA imagery**, not generated art.
Real Mars must look like real Mars — that is a scientific-accuracy requirement,
not an aesthetic preference.

This file logs prompts only for **stylized celestial art** that is deliberately
not photographic: storybook page illustrations of a planet, painted skies,
decorative borders around a real texture, and similar.

Generator: **Nano Banana Pro**

## Rule

If the image teaches the player what a body actually looks like, it comes from
NASA. If the image sets a mood or frames a scene, it can be generated. When in
doubt, use the real photograph.

## Format

```
### <body> — <purpose>
- **File**: assets/images/generated/<file>.webp
- **Date**: YYYY-MM-DD
- **Prompt**: <exact prompt string>
- **NASA source used alongside**: <url or file, if any>
- **Notes**: <retries, what to avoid>
```
