# Character Prompts

Log every prompt used to generate character art here, verbatim, so future
generations stay visually consistent. Never paraphrase a prompt after the fact —
copy the exact string that produced the asset.

Generator: **Nano Banana Pro**

## Format

Each entry records the prompt, the file it produced, and anything that had to be
retried. The "Notes" line is where a failed variation gets recorded so it is not
attempted twice.

```
### <asset-name>
- **File**: assets/images/generated/<file>.webp
- **Date**: YYYY-MM-DD
- **Prompt**: <exact prompt string>
- **Notes**: <what worked, what was retried, what to avoid>
```
